# 🐕 Ada's Math Quest

A dog-themed math game for 2nd graders (ages 7-9). Help rescue lost dogs in a magical forest by solving math challenges!

## 🎮 [Play the game →](https://macat.github.io/adas-math-quest/)

## Features

- **6 levels** with increasing difficulty
- **Math up to 100**: addition, subtraction, multiplication, division
- **Pattern recognition**: number sequences, missing numbers, comparisons
- **Word problems**: dog-themed story problems
- **Dog rescue theme**: save cute dogs lost in a magical forest
- **Sound effects** (Web Audio API — no files needed)
- **Timer + Records**: tracked in IndexedDB, beat your best times
- **3 languages**: English 🇬🇧, Deutsch 🇩🇪, Magyar 🇭🇺
- **Mobile-friendly**: works on tablets and phones

## Levels

| Level | Name | Skills |
|-------|------|--------|
| 1 | 🌱 Sunny Meadow | Addition & subtraction up to 20 |
| 2 | 🌿 Whispering Woods | Up to 50 + patterns |
| 3 | 🌲 Deep Forest | Up to 100 + multiplication (×2, ×5, ×10) |
| 4 | 🏔️ Mountain Trail | Mixed operations + harder patterns |
| 5 | 🌊 Crystal Lake | All operations + sequences |
| 6 | 🏰 Dragon's Den | Boss level — everything mixed! |

## Tech

Pure HTML/CSS/JS — no dependencies, no build step. Just open `docs/index.html` or visit the GitHub Pages site.
